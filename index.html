A personal desktop email client for Omarchy

Omarmail is a desktop email client that runs on the operator's own Linux computer (Omarchy). It is a personal instance of Omamail, an open-source plugin released under the MIT License, and is operated by imwsl for their own Gmail account.

What it does

  • Reads, searches, labels, archives and replies to Gmail in a native desktop window.
  • Sends messages that the user writes.
  • Shows meeting invitations and the user's calendar, and lets the user answer invitations and create or update events.

Google data it uses

Omarmail signs in with Google OAuth and requests only these scopes:

  • https://www.googleapis.com/auth/gmail.modify — read messages and labels, change labels, archive, and move to trash (it cannot permanently delete mail).
  • https://www.googleapis.com/auth/gmail.send — send messages the user composes.
  • https://www.googleapis.com/auth/calendar.events — read calendar events and create or update events.

All processing happens on the user's own computer. There is no Omarmail server: data travels only between that computer and Google's APIs. See the Privacy Policy for details.

一个自用的 Omarchy 桌面邮件客户端

Omarmail 是运行在使用者自己 Linux 电脑（Omarchy）上的桌面邮件客户端，是开源插件 Omamail（MIT 许可证）的一个个人实例，由 imwsl 运营，供其本人的 Gmail 账号使用。

功能

  • 在原生桌面窗口中阅读、搜索、标记、归档和回复 Gmail 邮件。
  • 发送用户自己撰写的邮件。
  • 显示会议邀请和日历，允许用户回复邀请、创建或修改日程。

使用的 Google 数据

Omarmail 通过 Google OAuth 登录，只申请以下权限范围：

  • gmail.modify：读取邮件和标签、修改标签、归档、移入垃圾箱（无法永久删除邮件）。
  • gmail.send：发送用户撰写的邮件。
  • calendar.events：读取日历事件，创建或修改事件。

所有处理都在用户自己的电脑上完成。Omarmail 没有服务器，数据只在这台电脑和 Google API 之间传输。详见隐私政策。

Omarmail 与 Google 没有关联，也未获得 Google 的认可或赞助。Gmail 和 Google 日历是 Google LLC 的商标。
